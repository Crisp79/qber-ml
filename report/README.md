# Research Report Generator

This directory contains the LaTeX source and build system for the QBER-ML research report.

## Structure

```
report/
├── main.tex                 # Main LaTeX document
├── references.bib           # Bibliography
├── sections/                # Section files (included via \input)
│   ├── introduction.tex
│   ├── background.tex
│   ├── dataset.tex
│   ├── methodology.tex
│   ├── results.tex
│   ├── discussion.tex
│   ├── limitations.tex
│   ├── future_work.tex
│   └── conclusion.tex
├── figures/                 # High-resolution figures (PNG/PDF)
├── generated/               # Build artifacts (created during compilation)
│   ├── main.pdf            # Final PDF report
│   ├── results_table.tex   # Auto-generated results table
│   └── ablation_table.tex  # Auto-generated ablation table
└── README.md               # This file
```

## Prerequisites

### LaTeX Installation (Required)

**Windows (recommended): MiKTeX**
1. Download from: https://miktex.org/download
2. Run installer (choose "Install for all users" if admin)
3. After installation, open "MiKTeX Console" and run "Check for updates"
4. Ensure `latexmk` is in PATH (usually automatic)

**Alternative: TeX Live**
1. Download from: https://tug.org/texlive/
2. Run `install-tl-windows.exe`
3. Add to PATH: `C:\texlive\2024\bin\windows`

**Verify installation:**
```powershell
latexmk --version
```

### Python Dependencies

Already installed via `uv sync`:
- `jupyterlab`, `ipykernel`, `nbconvert` (for notebook execution)
- `matplotlib`, `seaborn` (for figure generation)
- All ML dependencies

## Generating the Report

### Option 1: From saved results (fast, ~30 seconds)
```powershell
uv run python scripts/generate_report.py
```

### Option 2: Re-execute notebook + generate (slow, ~2 minutes)
```powershell
uv run python scripts/generate_report.py --execute-notebook
```

### Option 3: Custom output path
```powershell
uv run python scripts/generate_report.py --output results/exports/report.pdf
```

### Option 4: Full workflow (pipeline + notebook + report)
```powershell
uv run python scripts/build_research_artifacts.py
```

## Output

The final PDF is saved to:
- `report/generated/main.pdf` (default)
- Custom path if `--output` specified

## Common Errors and Fixes

| Error | Solution |
|-------|----------|
| `latexmk not found` | Install MiKTeX or TeX Live; ensure in PATH |
| `File 'main.tex' not found` | Run from project root directory |
| `Missing figure: figures/*.png` | Run pipeline first: `uv run python scripts/run_pipeline.py` |
| `Notebook execution timeout` | Increase timeout or run with `--no-notebook` |
| `Citation undefined` | Run `latexmk` twice (handled automatically) |
| `Font not found` | MiKTeX: run `initexmf --mkmaps` in admin terminal |

## Manual LaTeX Compilation

If the script fails, compile manually:

```powershell
cd report
latexmk -pdf -interaction=nonstopmode -outdir=generated main.tex
```

## Figures

All figures are generated by the ML pipeline (`scripts/run_pipeline.py`) and saved to `results/`. The report generator copies them to `report/figures/`.

Expected figures:
- `class_distribution.png`
- `feature_correlation.png`
- `model_comparison.png`
- `confusion_matrices.png`
- `per_class_f1.png`
- `roc_curves.png`
- `shap_importance.png`
- `ablation.png`

## Tables

Two tables are auto-generated from `results/evaluation_results.json`:
- `generated/results_table.tex` → Table 1 (multiclass results)
- `generated/ablation_table.tex` → Table 2 (ablation results)

These are included in `main.tex` via `\input{generated/results_table}` etc.

## Customization

To modify the report:
1. Edit section files in `sections/`
2. Edit `main.tex` for structure/preamble
3. Edit `references.bib` for citations
4. Re-run `generate_report.py`

## Dependencies Between Artifacts

```
run_pipeline.py
    ├── models/*.joblib
    ├── results/evaluation_results.json
    └── results/*.png
         ↓
generate_report.py (--execute-notebook)
    ├── executes qad_experiments.ipynb
    ├── copies figures to report/figures/
    ├── generates tables from evaluation_results.json
    └── compiles main.tex → generated/main.pdf
```

## Version Control

**Commit to Git:**
- `main.tex`, `references.bib`, `sections/*.tex`, `README.md`
- `scripts/generate_report.py`, `scripts/build_research_artifacts.py`

**Do NOT commit:**
- `generated/` (build artifacts)
- `figures/` (generated by pipeline, regenerated on demand)
- `*.aux`, `*.log`, `*.fls`, `*.fdb_latexmk` (LaTeX temp files)
